# LAW [2026-09-15]: PROVENANCE — born 2026-09-15 from .dev/research/setup-wizards-2026-09-15.md, the study of the PostHog wizard, torad-toolkit and splice setup. THE FINDING: splice is not behind on taste, it is behind on WIDGETS. PostHog and torad both stand on the clack prompt library; splice has seven ANSI constants in CliStyle.kt and readlnOrNull behind a y/n wrapper. Four primitives close the gap: select, multiselect, note, spinner. Operator authorized the build on 2026-09-15.
# LAW [2026-09-15]: HAND-ROLLED, NO NEW DEPENDENCIES — the toolkit is built against CliStyle.kt and the JDK. No mordant, no jline, no clikt, no picocli. The study weighed a library and chose hand-rolling as the in-character option for this repo; a dependency here would also mean verification-metadata churn for four widgets. Orchestrator call, reversible at any time by the operator.
# LAW [2026-09-15]: KOTLIN STYLE IS LAW — no top-level functions, no companion objects. Widgets are classes or objects with members. Enforced by the ast-grep pack at .rules/kotlin-splice (no-loose-function, no-companion-objects) and by konsist ArchitectureLawsTest, and promoted to a gate leg on 2026-08-17. Top-level const vals, interfaces, fun interfaces and data classes remain legal, as CliStyle.kt and AddSeams.kt already show. Do not relitigate this law.
# LAW [2026-09-15]: RESTORE THE TERMINAL, ALWAYS — raw mode is entered only inside a construct that restores it on normal return, on exception, on cancel, and on SIGINT. A wizard that leaves a terminal in raw mode with echo off is strictly worse than no wizard, because the damage outlives the process. This is the single highest-risk surface in the campaign and it gets a wall before it gets a widget.
# LAW [2026-09-15]: NON-TTY IS A FIRST-CLASS PATH, NOT AN ERROR — every widget returns its default when System.console() is null. It never blocks, never prompts, never hangs, never enters raw mode. Docker, CI, systemd start and piped invocations all run this path, and AdminSupport.confirm at AdminSupport.kt:172 already sets the precedent the whole toolkit follows.
# LAW [2026-09-15]: NEVER BELOW STATUS QUO — splice setup works end to end at every commit of this campaign. What must survive untouched in behaviour: the per-head sign-in walk with its unofficial-OAuth warning, the credential hygiene where every head owns its own file, the four-line next-steps block, and the headless default-return. A prettier wizard that regresses any of those is a failure, not a trade.
# LAW [2026-09-15]: FENCES ARE EXCLUSIVE per in-flight row. Every file has exactly ONE owner slot at a time. A builder that needs a file outside its fence REPORTS it to the orchestrator and stops; it never edits across a fence, and never silently widens one.
# LAW [2026-09-15]: BUILDERS NEVER COMMIT AND NEVER PUSH. The orchestrator owns the single gated commit per row: snapshot the fenced delta into a detached worktree at the CURRENT tip, gate it there, prove the shared worktree cached diff is byte-identical to the gated tree, then commit. Builders write code and run their own targeted module tests.
# LAW [2026-09-15]: PREMISE-CHECK DUTY — a wrong premise in a packet, INCLUDING one written by the orchestrator, is reported rather than obeyed. A guard that blocks a write is fixed at the code or escalated, never bypassed, never renamed around. Three failed fix-forward rounds on one row becomes a dated BLOCKED note and the row moves on; the block IS a result.
# LAW [2026-09-15]: NO BUMP, NO CUT, NO MERGE, NO PR without an explicit operator go. Gated work is committed and pushed to feat/v0.4.0 without asking. Standing constraint carried from the v0.4.0 campaign.
# LAW [2026-09-15]: THE SEAM THAT MAKES IT TESTABLE IS WHERE THE PRODUCTION DEFAULT HIDES. Three of the first four rows shipped a defect of exactly this shape and every one of them had a GREEN suite. CW-1: the injected stty fake always succeeded, so the failure path was never exercised and a failed capture would have left the terminal raw. CW-3: the non-TTY branch diverged from the interactive branch and only the interactive branch was covered, so the HEADLESS path was the unsafe one. CW-6: controlPort is injectable and every test supplied its own value, so the hardcoded default was never evaluated and it silently re-introduced a bug AdminSupport.kt:50-53 documents as already fixed. RULE for every remaining row: when a constructor takes an injected seam WITH A DEFAULT, at least one test must exercise the DEFAULT, or the default must be derived from a single source that is itself tested. A green suite over injected fakes says nothing about what production constructs.
