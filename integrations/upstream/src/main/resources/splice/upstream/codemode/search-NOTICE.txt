CodeMode search tokenizer source and data

Exact versions used by Codex rust-v0.164.0 (6aaac694803004a63c6f393d153c96d22521a6b9).
The Kotlin implementation ports bm25 default_tokenizer.rs, unicode-segmentation ASCII word rules,
and rust-stemmers algorithms/english.sbl. Normalization data is copied byte-for-byte from deunicode.
English stopwords are emitted by stop-words::get(LANGUAGE::English).
