## Suggested order

1. Finish the UI inspection/fixes and as-built product review pack on the feature branch.
2. Commit the intended runtime, UI, stable-marker and documentation changes; record its SHA.
3. Run the complete release gate on that committed SHA. Its release rehearsal stages and
   accepts `dist/` in the persistent gate tree; retain that bundle and hashes without a second build.
4. Push only the feature branch through its mandatory pre-push hook; observe checks after
   the account billing lock is resolved. Present the inspected UI/product pack for disposition.
5. Keep main merge and publication on hold. After the hold is explicitly lifted, merge the
   reviewed tree and verify the resulting main SHA before normal prod promotion/publication.
6. On authorized installation, follow the documented backup/atomic-install/restart procedure
   and verify the running process's open jar hash, installed launcher, health/version and
   update channel. [Install procedure](../../CLAUDE.md#how-an-install-runs-once-it-is-due-2026-09-16).
