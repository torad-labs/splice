# LAW [2026-09-18]: AN ASSERTION THAT NAMES A DEFECT DIES THE DAY THE DEFECT IS FIXED. Pin the PROPERTY, never the FINDING. The tell is grammatical: an assertion whose subject is a number you just measured, or a line you just read in today's output, is pinned to today. An assertion whose subject is a relationship that must hold for the code to be correct survives its own success. A wall that a fix turns red is not a wall, it is a bookmark -- and the seat that meets it will edit the wall, because the fix is obviously right and the wall is obviously stale. THE SAME MECHANISM RUNS ON LEGITIMATE CHANGE TOO, AND IT IS HOW GUARDS ACTUALLY DIE (claude-splice-main, 2026-09-18, improving on this seat's remedy for the V4-157 golden): GUARD THE SHAPE, NEVER THE BYTE. A guard is only as durable as its false-positive rate, which is a fact about the people maintaining it and not about the code.
