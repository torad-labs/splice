# Current reference history

The two `0.164.0` archives preserve the complete original 14,615-unit source
census and every original disposition, including unsupported obligations.
`current-history.ts` checks their compressed and decoded SHA-256 identities on
every current qualification/readiness load. A reference refresh cannot replace,
shrink, or silently resolve this historical record.

`current-inventory.json` is independently regenerated from the selected current
official Git revision. It includes additions and changed declarations. A byte
offset is revision-specific: an upstream insertion can change a unit's ID while
its source body stays identical. `historySuccessors` reports exact body
successors, changed declarations, and upstream removals/moves for review. The
original IDs remain available in these archives in every case.

The archives are provenance and obligation history. They grant no current
execution coverage or qualification PASS. Current dispositions still need exact
current hashes and named mandatory cases; current receipts still need fresh
source/native verification, production executions, and installed identity.
